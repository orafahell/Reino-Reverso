# Assets da identidade "Arquivo corrompido"

Arquivos usados pela ficha de Reino Reverso no Roll20. A ficha carrega cada um pelo endereço
`https://raw.githubusercontent.com/orafahell/Reino-Reverso/main/<caminho>`, então renomear ou mover
um arquivo quebra a imagem na ficha.

## Logo (gerado a partir da fonte Doctor Glitch)

| Arquivo | Uso |
|---|---|
| `logo/logo-empilhado-branco.png` | Topo da ficha. REINO em cima, REVERSO espelhado embaixo, como na capa. |
| `logo/logo-empilhado-preto.png` | Mesma composição para fundo claro. |
| `logo/logo-linha-branco.png` | Versão em uma linha para fundo escuro. |
| `logo/logo-linha-preto.png` | Versão em uma linha para fundo claro. |

## Texturas (chiado de televisão)

Todas são ladrilháveis: as bordas se encaixam, então podem repetir como fundo.

| Arquivo | Uso |
|---|---|
| `texturas/estatica-escura.jpg` | Fundo do topo, dos blocos do Reverso e do cabeçalho do cartão no chat. |
| `texturas/estatica.jpg` | Chiado em contraste alto, para peças de divulgação e destaques. |
| `texturas/estatica-papel.jpg` | Chiado leve sobre o tom de papel, para fundos claros. |
| `texturas/varredura.png` | Linhas de varredura de TV (ladrilho de 4×6 px, fundo transparente). |
